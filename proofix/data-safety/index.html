Français English

Pratiques générales

  • Chiffrement : toutes les données sont transmises de façon chiffrée (HTTPS).
  • Aucun compte : pas d'inscription, pas de nom ni d'adresse e-mail demandés.
  • Aucune vente de données.
  • Suppression : l'historique se supprime dans l'application ; la désinstallation efface toutes les données stockées sur le téléphone. Pour toute autre demande : proofix.app@gmail.com.

General practices

  • Encryption: all data is sent encrypted (HTTPS).
  • No account: no sign-up, no name or email address requested.
  • We do not sell data.
  • Deletion: history can be cleared in the app; uninstalling removes all data stored on the phone. For any other request: proofix.app@gmail.com.
